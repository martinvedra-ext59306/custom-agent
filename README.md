# custom-agent

Ukázka minimální konfigurace pro vyzkoušení custom Copilot agenta.

## Copilot setup steps

Soubor `.github/workflows/copilot-setup-steps.yml` připraví prostředí agenta.

Jak ověřit:

1. Otevři **Actions** v repozitáři.
2. Spusť workflow **Copilot Setup Steps** ručně přes **Run workflow**.
